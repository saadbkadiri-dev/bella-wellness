# Bella Wellness Project Context

## Overview
Bella Wellness is an exclusive sanctuary designed entirely for women to move, heal, and glow. It is built as a highly responsive, modern, minimalist Next.js web application.

## Tech Stack
- Framework: Next.js 15 (App Router)
- React: 19
- Styling: Tailwind CSS v4 (using `@theme` in `globals.css`)
- Typography: Montserrat site-wide (all headings and body text) via `next/font/google`, weights 300–700. Libre Caslon Display and Sora have been removed — the editorial serif/sans contrast is gone in favor of a single typeface differentiated by weight.
- Animations: Framer Motion (for staggered reveals, asymmetric transitions, and hero slide carousel)
- Smooth Scrolling: Lenis

## Design System & Rules
- **Aesthetic:** Editorial, organic, tactile, high-end luxury.
- **Layout:** Asymmetric split layouts (e.g., 55% text, 45% image), fluid overlapping, left-aligned text preference.
- **Hero Headline Case:** Displayed uppercase via CSS `text-transform` (Tailwind `uppercase` class), `font-light` weight. "For Women." is joined with a non-breaking space so it never breaks across lines; "Sanctuary" can still wrap onto its own line.
- **Kicker/Eyebrow Labels:** Small uppercase section labels (e.g. "OUR SANCTUARY • BEIRUT") are `13px`/`font-semibold` sitewide (bumped up from `11px`/`font-medium`).
- **Fluid Type Tiers:** `.text-fluid-hero` (hero h1), `.text-fluid-h2` (large section headings — About, Why Bella Wellness), `.text-fluid-h3` (smaller section headings — Intro Strip, Services), `.text-fluid-body`.
- **Avoid:** Generic blocks, cards with heavy drop shadows, rounded pills, horizontal dividers, and centered AI-looking templates.
- **Phase 1 Rules:** Zero CTAs or buttons. No external booking links yet. Note: the hero headline now reads "SANCTUARY FOR WOMEN." per explicit user request, diverging from `content.md`'s canonical tagline ("A community of women thriving in wellness."); `content.md` itself has not been updated to match, and the Footer no longer displays that tagline quote at all (it was removed).
- **Long Hyphens:** Em dashes (—) have been removed from all site copy (hero, About page body text, `content.md` source) in favor of plain short hyphens ( - ), per explicit user request. Not yet codified as a standing rule — confirm with user before treating as permanent.
- **Deploy Rule:** Do NOT deploy to Vercel without explicit user permission.

## Current State
- The landing page (`/`), About (`/about`), and Gallery (`/gallery`) pages are fully implemented.
- Navbar and Footer both use the dark wordmark (`word-bella.png`) and emblem on Bella's warm linen palette (`#F6F3EF`) — Footer was recently flipped from a dark charcoal theme to match the Navbar; `word-bella-light.png` is no longer referenced anywhere.
- Hero section is a full-screen cinematic slideshow (5 images, 6s interval, crossfade + Ken Burns zoom). Headline is "SANCTUARY FOR WOMEN." (uppercase, font-light, "For Women." locked to one line via non-breaking space); eyebrow tag reads "• BELLA WELLNESS" with a bullet dot prefix. Navigation is swipe/drag, keyboard arrow keys, and progress-line indicators only — the prev/next arrow buttons were removed entirely.
- Services section (`ServicesGrid.tsx`): kicker renamed to "BELLA'S OFFERINGS"; heading ("Comprehensive Care / & Sanctuary") is hard line-broken so the `&` stays with "Sanctuary". Desktop (`lg:` and up) keeps the accordion: the sticky left image stretches (`items-stretch`/`h-full`) to match the full height of the 01–05 list and is clipped into the Bella arch/emblem silhouette via an inline SVG `clip-path` (not a CSS `mask-image` — that faded the photo, since raster masks use luminance and the arch asset isn't pure white), with a wave-texture overlay painted directly on top (no `mix-blend-mode` — that made the texture invisible against the photo; plain paint at higher opacity/weight is used instead). The accordion starts fully collapsed and each item now toggles closed on a second click (previously stayed open once opened). Below `lg`, the accordion is hidden entirely and replaced with a horizontal swipe/scroll-snap carousel (one full slide per service, same texture overlay on each slide's image, thin progress-line indicators tracking scroll position). The Movement and Fitness, Recovery and Relaxation, and Beauty Salon images have a per-service `imagePosition` (`object-position`) so the people in frame aren't cropped out (Recovery and Beauty Salon crop toward the left of the source photo; Movement and Fitness crops toward the right, since its subjects sit on that side of the source image — don't assume "left" applies to all three); applied on both the desktop and mobile image renders.
- IntroStrip ("Welcome to Bella Wellness...") now carries the same faint hand-drawn wave SVG texture (tiled 80x80px, low-opacity strokes) used on the Preloader loading screen, layered over its linen background.
- WhyBellaPillars ("Why Bella Wellness") also carries the Preloader wave texture. Below `lg` it's full-width numbered editorial rows (large serif numerals, hairline dividers); at `lg` and up it's four tiles in one row, solid `#F9F7F4` fill, hairline border, no fixed aspect ratio — the grid's default `stretch` sizing makes all four match the tallest tile's content height, rather than each being capped independently (a fixed `aspect-[5/4]` per tile caused overflow on longer descriptions and inconsistent heights). Neither the section title nor the tile row is nested inside the page's standard `max-w-7xl` content column — both are full-width siblings with matching edge padding, flush-left with each other and spanning the true page width (nesting either inside `max-w-7xl` capped it at 1280px and misaligned it from the tiles on wide screens).
- Footer padding/sizing tightened throughout (reduced top/bottom padding, grid gaps, logo size) — it was reported as too large. The brand-column tagline quote was removed entirely, a "Designed by: thequarter8" credit was added to the bottom bar alongside the copyright line, and "Sanctuary for Women in Ohana Hills" is now `font-semibold`.
- High-contrast frosted navigation bar in Bella's warm linen palette (`#F6F3EF`), no longer capped at `max-w-7xl` — its content (logo + nav links) now spans the true full page width like the rest of the reworked layout. Mobile logo lockup is smaller/tighter than desktop. The mobile menu had a real layout bug: it's `position:fixed` + `display:flex; flex-direction:column` with both `top` and `bottom` set, which is a known browser bug where the flex children contribute nothing to the auto-height calculation, collapsing the menu to ~97px instead of filling the screen (page content showed through below the first nav link). Fixed by giving it an explicit `h-[calc(100dvh-72px)]` instead of relying on `bottom`+`height:auto`. The mobile menu is now a full-page takeover with the same wave texture as Intro Strip/Why Bella Wellness, and no longer shows "Ohana Hills • Beirut".
- Preloader's exit is a single straightforward fade (whole preloader — background, texture, and logo together as one unit — opacity 1→0 over 0.9s via Framer Motion). This replaced two earlier particle-dissolve attempts (a chunky ~84-tile grid, then a fine 720-tile grid): both looked "bulky"/busy in practice, so the component was simplified back down rather than tuned further. There's no separate logo-vs-background layer anymore, so there's nothing to desync.
- Local Next.js dev server running with Fast Refresh (`localhost:3000`).
- Repository hosted on GitHub (`saadbkadiri-dev/bella-wellness`), manual Vercel deploys only per user instruction.
